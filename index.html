¿Cómo se interpreta?

MaxDiff significa Maximum Difference Scaling (escalamiento de diferencia máxima). Presenta conjuntos de elementos y pide elegir el más y el menos importante. Al repetirlo con varias personas, se identifican prioridades relativas. Este ejemplo usa un conteo sencillo para enseñar la mecánica; no es un modelo estadístico avanzado.

¿Cómo funciona?

  • En cada ronda aparecen 4 características.
  • Selecciona una como la más importante.
  • Selecciona otra como la menos importante.
  • Completa las 4 rondas.

¿Para qué sirve?

Ayuda a priorizar funcionalidades, beneficios o atributos cuando no todo puede tener la misma importancia.

Ejemplo UX

Un equipo quiere decidir qué destacar en una app de comida: rapidez, precio, variedad, seguimiento u otras características.

Nota para el docente

MaxDiff obliga a establecer preferencias relativas. A diferencia de una escala de opinión, no permite calificar todo como “muy importante”. Para una investigación real se requieren varios participantes, conjuntos equilibrados y un análisis apropiado.
